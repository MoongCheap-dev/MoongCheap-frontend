# 보안 최소 요건 (security baseline)

MoongCheap 화면·기능을 구현할 때 **인프라/백엔드 팀이 최소한 지켜주어야 하는** 보안 기준입니다.
프론트가 단독으로 보장할 수 없는 항목(쿠키 설정, HTTPS 강제, CSP 헤더, 서버단 재검증 등)이 많아, 요건을 문서로 못박아 둡니다.

> ⚠️ 아직 백엔드와 **미합의** 상태입니다. 인증 방식(Authorization 헤더 vs httpOnly 쿠키)은 `CLAUDE.md`·[`deferred-setup.md`](./deferred-setup.md)에 미확정으로 남아 있습니다. 아래는 "이렇게 가야 한다"는 프론트 측 요청이며, 규격 확정 시 이 문서를 갱신합니다.

## 최소 요건

| #   | 요건                                                                                                  | 담당                                 | 프론트 영향                                                               |
| --- | ----------------------------------------------------------------------------------------------------- | ------------------------------------ | ------------------------------------------------------------------------- |
| 1   | **인증 토큰은 httpOnly 쿠키 등 안전한 저장 방식** 사용. `localStorage`에 평문 저장 금지               | 백엔드(쿠키 발급)·프론트(저장 안 함) | 토큰을 JS에서 읽지 않는 구조 전제. 로그인 상태 판별을 API 응답에 의존     |
| 2   | **클라이언트 입력 검증은 UX 목적일 뿐**, 서버단 재검증 없이 신뢰하지 않기                             | 백엔드                               | 프론트 `zod`/`react-hook-form` 검증은 편의용. 서버가 동일 규칙으로 재검증 |
| 3   | **사용자 생성 콘텐츠 출력 시 이스케이프 처리 (XSS 방지)** — 상품 요청 설명, 셀러 제안 메시지, 리뷰 등 | 프론트                               | `dangerouslySetInnerHTML` 지양. 불가피하면 서버·클라 양쪽 sanitize        |
| 4   | **결제 페이지는 카드 정보를 직접 다루지 않음** — PG사 토큰화/iframe 방식 사용                         | 백엔드·PG 연동                       | 카드번호·CVC를 프론트 상태나 폼에 담지 않음. PG SDK/iframe에 위임         |
| 5   | **로그인·결제 등 민감 페이지는 HTTPS 강제 + CSP 헤더 적용**                                           | 인프라                               | 프론트는 CSP에 맞춰 인라인 스크립트·외부 리소스 정리                      |

## 프론트가 이 문서를 근거로 지킬 것

- 토큰을 `localStorage`/`sessionStorage`에 저장하는 코드 작성 금지 (요건 1)
- 폼 검증을 통과했다는 이유로 서버 응답을 낙관하지 않기 — 에러 응답 처리 필수 (요건 2)
- 사용자 입력을 그대로 HTML로 렌더링하지 않기 (요건 3)
- 결제 플로우에서 카드 원문 데이터를 프론트 코드가 만지지 않기 (요건 4)
- CSP 위반을 유발하는 인라인 `<script>`·임의 외부 스크립트 삽입 지양 (요건 5)

## 재검토 시점

- 인증 방식(쿠키 vs 헤더)이 확정되면 요건 1을 실제 구현 규칙으로 구체화
- 결제 PG사가 정해지면 요건 4에 SDK/iframe 연동 방식 추가
- 배포 인프라(CSP·HTTPS 설정 위치)가 정해지면 요건 5의 담당·설정 파일 명시
